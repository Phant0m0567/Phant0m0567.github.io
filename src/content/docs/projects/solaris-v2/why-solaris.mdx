**Solaris V2** is a state of the art web proxy, built for browsing the internet without fear of IP loggers, content restrictions, and cencorship. Solaris is built in TypeScript and Vue, and is built to reduce lag and unnececary complexity while still providing a **fast**, **safe**, and **customizable** browsing experience.


## Features

**Solaris V2** is a lightning fast proxy with everything you could possibly wish for from a UBG site.

 Some of its many features include:

- A lightning fast proxy powered by Scramjet + Ultraviolet.
- A massive game library.
- Cloud Gaming and dedicated Windows/Linux VMs.
- A Spotify Music Player.
- Unblocked Youtube via Invidious.
- And much more! 

## Our Principles

Here are the three core design principles that guide how we build Solaris.


### Content-Driven

**Solaris** strives to provide the best possible experience, whether you're browsing, gaming, watching, or anything in between. We aim to excel in any of these aspects, while still trying to be something **original**, rather than skidding and copying what already has been made.

No matter what blockers or content restrictions you have, Solaris V2 is made to help you get around them. We believe your experience shouldn't be interrupted by ads, tracking cookies, or your data being harvested.

### Fully Open-Source

**Solaris V2** is fully open-source, and you can find our GitHub repository [here](https://github.com/phant0m0567/solaris-v2). We believe users should know exactly what they're using and how it works. This however doesnt justify **skidding**, ditributing modified code, claiming ownership of said code, or using the code without crediting Solaris or it's original owners. It is against our ToS and will result in **legal action**.

We are always looking for new developers, designers, channel managers, and new suggestions! If you are interested in contributing to Solaris, please join the [discord](https://discord.com/invite/RQe55a2uhS), or submit a pull request or issue on our GitHub [repository](https://github.com/phant0m0567/solaris-v2).

### Fast by Default

**Solaris** is built with performance in mind, aiming to provide the fastest experience possible across every use case, whether you're browsing, gaming, streaming, or chatting. We continuously work to optimize performance, reduce unnecessary overhead, and keep everything running smoothly.
